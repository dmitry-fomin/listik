Listik — общий трекер задач для людей и ИИ-агентов: карточка → база → агенты-харнессы (Claude Code, Codex…) ведут её по этапам маршрута → рой вливает код в main; вопросы к вам — в колонке «Нужен ты». Нажмите на блок или статус — появится подсказка.

Статусы — нажмите, чтобы увидеть, где ставятся

Куда уходят данные

  • Карточки, журнал, события, память: от человека и агентов → одна база SQLite на машине владельца → доска в браузере по токену. Наружу Listik их сам не отправляет.
  • Код и ТЗ: пишут агенты в отдельном дереве задачи → ветка → main проекта. В базе — только пути к файлам. Пуш в удалённый репозиторий рой не делает.
  • Что видят модели: агент-харнесс отправляет своему поставщику модели то, что сам прочитал в дереве задачи и карточке; модели-арбитру рой отдаёт только файлы с конфликтом.
