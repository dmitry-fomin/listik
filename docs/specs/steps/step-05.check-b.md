## Ряд чипов и фильтры

11. `.listik-toolbar` под инбоксом содержит слева пять `.ui-chip`: «{n} брошена», «{n} под
    угрозой», «{n} стоят из-за других», «{n} можно брать», «{n} в конвейере»; первые четыре —
    `<button aria-pressed>` (интерактивные), пятый — `<span>`. На моке: «стоят из-за других» = 1,
    «можно брать» = число из `/api/board.ready`, «в конвейере» = число задач со `stage` s1–s4 (4),
    «брошена» ≥ 2 (`stale` + `abandoned`).
12. Клик по «стоят из-за других» → на доске остаётся только `listik-metrics-g7h8`, чип получает
    `aria-pressed="true"`; повторный клик снимает фильтр. «брошена» и «под угрозой»
    взаимоисключающие (клик по одному снимает другой); «можно брать» и «стоят из-за других» —
    тоже; «брошена» + «можно брать» могут быть активны одновременно. Клик по чипу не сбрасывает
    выбранный проект.
13. Справа: `UiSelect` проекта с плейсхолдером «все проекты» (выбор проекта перезапрашивает
    `/api/board?project=…`; рядом появляется `ProjectMark` выбранного), чип «закрытые»
    (`aria-pressed` ↔ `include_closed=1` в запросе `/api/board`), поле поиска с иконкой и
    плейсхолдером «поиск по задачам · Cmd K». Селекта «харнесс» **нет**.
14. `Enter` в поле поиска с текстом открывает `UiCommandPalette` с результатами `/api/search`;
    `Cmd/Ctrl+K` открывает её же; выбор результата открывает панель задачи. Инлайн-списка
    результатов и сегмента `hybrid/text/vector` на странице нет.
    Повторное открытие: открыть палитру по `Cmd/Ctrl+K`, закрыть `Esc`, ввести в тулбаре «доска»
    и нажать `Enter` — палитра показывает результаты, текст «доска» в поле тулбара на месте;
    закрыть, снова `Enter` — результаты те же, поле не очищено; открыть по `Cmd/Ctrl+K` без
    ввода — `store.query` и результаты не сброшены (в `MOCK_LOG=1` нет запроса `/api/search?q=`
    с пустым `q`). **Красный до правки** (при старом `onPaletteSearch`): после второго открытия
    поле пустое, результатов нет.
15. На вкладке «Доска» `.ui-filter-bar` отсутствует; на «Списке» — ровно один, первым блоком,
    без поля «Проект» и без чекбокса «закрытые», с сегментом «здоровье: все / брошены / под
    угрозой» вместо чекбокса «только брошенные»; выбор «брошены» оставляет в таблице только
    задачи со `stale`/`abandoned`. В шапке «Списка» нет второго сегмента зависимостей.
16. Панель задачи, открытая при активном чипе/проекте, после закрытия не сбрасывает их
    (`aria-pressed` и значение селекта те же).
