## Раскладка 1024–1279

16. `npm run smoke -- http://localhost:5173/ 1024`: `board.intakeCollapsed === true`,
    `layout.columnsVisible === 4` (считаются только `data-stage` s1–s4; «Заведена» и «Готово» в
    счёт не входят), `layout.s4Right ≤ 0` (правый край колонки s4 не выходит за `innerWidth`),
    `layout.boardOverflow > 24` (рельса «Готово» уходит в прокрутку контейнера доски),
    `layout.безГоризонтальнойПрокрутки === true` (документ не шире окна). Ширина s-колонок 208px,
    первой дорожки — 56px. **Красный до правки**: колонки 252px, s4 не помещается; при статичной
    сетке с первой дорожкой 232px — `s4Right > 0` даже при 208px.
17. Клик по свёрнутой «Заведена» разворачивает колонку (`aria-expanded="true"`, ширина 232px),
    доска прокручивается по горизонтали; повторный клик сворачивает. При 1440
    `intakeCollapsed === false` без кликов. Изменение ширины окна с 1440 до 1100 сворачивает
    «Заведена» само (matchMedia).
18. При 1440 `layout.boardOverflow ≤ 24` (ряд 1376px в контейнере 1376px минус вертикальный
    скроллбар страницы; у `.listik-board` нет боковых отступов) и правый край
    `.listik-done-rail` виден после прокрутки контейнера не больше чем на 24px; `layout.columnsVisible
    === 4` без прокрутки. При 1440 и активном чипе «закрытые» (колонка «Готово» 252px вместо
    рельсы 56px) горизонтальная прокрутка ряда допускается.
