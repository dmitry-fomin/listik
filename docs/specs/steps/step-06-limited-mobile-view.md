# Шаг 06. Ограниченный мобильный просмотр

## Цель

Дать возможность быстро посмотреть очередь с телефона, не строя вторую полноценную доску.

## Поведение

При viewport меньше 768 px показывается короткий список с заголовком, проектом, этапом,
health, holder и временем последнего heartbeat. Фильтр и поиск остаются доступными в компактном
виде. Нажатие открывает read-mostly detail page/drawer с acceptance, блокерами, последним review
и journal; редактирование допускается только для безопасных действий `claim/comment/needs-owner`
если они уже поддержаны API.

Не включать: полный Kanban, drag-and-drop, Metrics, Timeline, сложные faceted filters и
длинные текстовые поля в списке.

## Критерии приёмки

* Первый экран читаем на ширине 360 px без горизонтального скролла.
* Список загружает пагинацию/ограниченное число карточек и не тянет весь журнал.
* Можно открыть задачу и вернуться к тому же месту в списке.
* Desktop/tablet layout не меняется из-за mobile CSS.
