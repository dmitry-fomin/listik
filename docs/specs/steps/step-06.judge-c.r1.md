## Ширина панели (п. 17) — КРАСНОЕ

17. ❌ **Длинный заголовок без пробелов расширяет панель телефона.** Живая задача с заголовком
    из 65 символов без пробелов («ОченьДлинныйЗаголовокБезПробеловДляПроверкиШириныПанели1234567890»),
    устройство 360×740: `.ui-drawer` `getBoundingClientRect().width = 360`, но
    `.ui-drawer.scrollWidth = 738` (требование п. 17 — равен ширине вьюпорта, т.е. 360).
    Переполняет `h2.listik-drawer__title` из слота `#header`
    (`web/src/components/PhoneTaskSheet.vue:103`): у него `overflow-wrap: normal`,
    `scrollWidth 714` при ширине 271; `.ui-drawer__header` — `scrollWidth 738` при ширине 359.
    Правило `.listik-phone-sheet { overflow-wrap: anywhere }`
    (`web/src/assets/app.css:149–151`) на шапку не распространяется — она вне
    `div.listik-phone-sheet`. `document.documentElement.scrollWidth` остаётся 360
    (`body` на телефоне с `overflow-x: hidden`), поэтому хвост заголовка просто уходит
    за край экрана и не читается.
    Тело карточки требование выполняет: у задачи, заблокированной этой же длинной задачей,
    блокер с тем же 65-символьным заголовком переносится —
    `.listik-phone-sheet__deps` `scrollWidth 311`, `.ui-drawer` `scrollWidth 359`.
    Факт для контекста (не часть вердикта): тот же класс в `TaskDrawer` на 800 px даёт
    `.ui-drawer` `scrollWidth 738` при ширине 720, т.е. поведение шапки унаследовано от
    существующей вёрстки; но на телефоне требование п. 17 не выполнено.
