Ядро конвейеров лежит по абсолютному пути:

`${CLAUDE_PLUGIN_ROOT}/references/pipeline-core.md`

Прочитай этот файл целиком инструментом Read до первого действия пресета. Без установленного плагина —
путь в репозитории: `plugins/pipeline-core/references/pipeline-core.md`.

Файла по пути нет — пресет стоит по разделу «Стоп-фактор» ядра: журнал `стоп: ядро — файл не найден: <путь>`,
`needs-owner` и тот же вопрос в чат. Ядро не восстанавливай по памяти и не бери из другой копии.
